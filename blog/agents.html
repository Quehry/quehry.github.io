What Should You Log in an Agent Experiment?

When an agent returns a wrong answer, its execution trace helps you see whether it failed while breaking down the task, calling a tool, or combining the results. Give each run an ID that ties together its configuration, steps, and final score.

Capture the Details of Each Step

  • Record the task input, model version, and tool permissions.
  • Record tool arguments, results, and errors. Redact credentials and private data before saving logs.
  • Record the stopping reason, task score, and findings from human review.

Make Traces Easy to Review

Start with one failed run. Ask whether another researcher could explain the outcome using the trace. If they would still need to dig through console output or chat history for a crucial detail, capture that field in the next experiment.
