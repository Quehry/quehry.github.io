How Do You Design a Convincing Model Evaluation?

Before running an evaluation, turn your hypothesis into a question you can answer with evidence. In a question-answering task that requires combining several sources, for example, at which step does the model lose track of the evidence it needs? The answer you seek determines how to group examples and which intermediate outputs to record.

Keep Experimental Conditions Consistent

Record prompt versions, sampling parameters, input length limits, and scoring rules. Give each method the same inputs and compute budget. Include a few borderline examples to show how the scoring rules apply.

Inspect Failure Cases

Break down results by task type and difficulty, then sample errors from each group. Look for missing evidence, gaps in reasoning, and formatting problems. Include a representative example of each failure mode so readers can judge which tasks the results apply to.
