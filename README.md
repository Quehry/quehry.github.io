# AI Researcher Homepage

An English-language static site with a researcher profile, publications, and a blog.

## Customize

- Edit `index.html` to update the profile, research interests, and publications. The paper entries are examples.
- Replace `Your Name` and `you@example.com` across the four HTML pages.
- To add a post, copy an article in `blog/`, update its title, date, description, and body, then add a link in `blog/index.html`. Update the featured posts in `index.html` as needed.

## Publish with GitHub Pages

1. Upload the site files to the root of a public GitHub repository. Keep `index.html`, `styles.css`, `field.js`, `.nojekyll`, and the `blog/` folder together.
2. In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**. Select the branch containing the files and **/(root)**, then save.
3. Once the deployment succeeds, open **Settings → Pages** and copy the public URL. Open the site in a private window and follow **Blog** to an article to verify public access.

No build command or runtime dependencies are required. To preview locally, open `index.html` in a browser.
